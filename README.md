# 30-Days-SQL-Micro-Course-Assignment

## 📚 SQL Assignment

This repository contains my SQL assignment, where I practiced writing SQL queries to solve different database-related problems. The assignment covers fundamental to intermediate SQL concepts used in real-world data analysis.

## 🎯 Objective

The goal of this assignment is to strengthen SQL skills by practicing different types of queries, data retrieval techniques, and database operations.

## 🛠️ Topics Covered

- SELECT Statement
- WHERE Clause
- ORDER BY
- GROUP BY
- HAVING Clause
- Aggregate Functions
- Joins (INNER, LEFT, RIGHT)
- Date Functions
- INSERT, UPDATE & DELETE

## 💻 Tools Used

- PostgreSQL
- SQL
